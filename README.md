# Run and deploy your dashboard

This contains everything you need to run your app locally.

> Note: this repository is currently configured for local development. The previously referenced AI Studio URL is not an active deployment.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## User documentation

- `docs/user-guide.md` — користувацький гайд, який описує кожну сторінку та як працювати з моделлю.
- Локально відкрийте `http://localhost:5173` після `npm run dev`.
