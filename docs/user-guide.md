# FEEL Again Dashboard — User Guide

## Як працювати з додатком

Запуск локально:

- Встановіть залежності: `npm install`
- Запустіть: `npm run dev`
- Відкрийте: `http://localhost:5173`

> Примітка: цей репозиторій налаштовано для локальної розробки. AI Studio URL наразі не є робочим.

## Структура екрану

- `L1` — стратегічний балансовий дашборд:
  - MHEI як стратегічний індекс
  - шість ключових компонентів та стан їх прогресу
  - індикатори живих/статичних джерел
  - оцінка ціни бездіяльності
  - кнопки для переходу до L2 та L4

- `L2` — детальна аналітика та моделі:
  - `l2-mhei` — інтерктивна дельта-модель MHEI та калькулятор беклогу
  - `l2-fintech`, `l2-clinical`, `l2-data`, `l2-sustain`, `l2-digital`, `l2-regulatory` — окремі L2 сторінки по програмах
  - `l2-analytical` — мапа даних, видимість API та джерел
  - `l2-journey` — stakeholder journeys з двома варіантами дельти

- `appendix` — L3 / оперативний бриф та вихідні дані
- `l4` — L4 повний аналітичний звіт

## Що показує `L2 Journey`

Ця сторінка демонструє одночасний таймлайн для трьох ролей:
- бенефіціар
- провайдер
- донор

Таймлайн починається з діагностики бенефіціара. На наступних фазах до процесу підключається провайдер, а потім донор.

Перемикач `With FEEL Again / Without FEEL Again` показує дельту між інтегрованим цифровим процесом і традиційним ручним шляхом.

## Як читати сторінку

- Колонки відповідають фазам процесу.
- Рядки відповідають ролям.
- Активна фаза підсвічується.
- Кнопка демонстрації автоматично проходить по наступних фазах.
